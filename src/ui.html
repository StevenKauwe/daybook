Settings · capture, retention, resources & providers

Stop before saving. Saving restarts the native bridge in the stopped state. All durations below are seconds unless named hours. Work hours use this Mac’s local timezone. Empty meeting_bundle_id records system audio; otherwise enter the meeting app’s bundle ID.

Set model_path to a local Moonshine tiny/base GGUF. Speechworks CPU inference is serial. Passive screen checks read text on this Mac, then release the image. A line keeps its first and last observed times. Save Screenshot saves an original you can open later.

Empty summary model uses a local extractive digest. For llama.cpp use http://127.0.0.1:PORT/v1. Hosted endpoints require HTTPS and remote_opt_in: true to send summary text to that endpoint.

Credentials: create a generic password in Keychain Access with service local.daybook.provider; put its account name in keychain_account. Never paste keys here. Budgets include failures and conservatively reserve UTF-8 bytes plus output tokens; images additionally reserve 8192 tokens. They are request limits, not guaranteed dollar or tokenizer limits.

Advanced configuration includes the summary provider, disk and memory budgets, and request caps.

Optional OpenCode metadata import: paste JSON with model and providers/settings/baseURL (current), or provider/options/baseURL (V1). JSONC comments and trailing commas are accepted. API keys and env/file substitutions are never copied or evaluated; imported remote settings remain disabled.
